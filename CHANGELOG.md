# Changelog

## 0.1.0 — 2026-11-27

- First public release of `@lola-market/cli`.
- `lola login` / `logout` / `whoami`: browser-approved device-flow login.
- `lola tools` and `lola call`: list and run the tools your account has.
- `lola-mcp`: stdio bridge to the hosted LOLA MCP server
  (`https://api.lola.market/lola-mcp`).
- MIT license.
