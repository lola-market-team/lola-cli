# Security policy

Please **do not open a public issue** for security problems.

Report vulnerabilities to **security@lola.market** or via GitHub's
[private vulnerability reporting](https://github.com/lola-market-team/lola-cli/security/advisories/new).
Include steps to reproduce and the affected version. We aim to answer within
3 working days.

In scope: this client, and the LOLA API endpoints it calls
(`api.lola.market`). Please don't run automated scanners or load tests against
production, and don't access other users' data. Use your own account.
